# Marketing Skills

**Claude skills I built for marketing teams: coaches that build a marketer's judgment instead of
handing over the finished answer.**

## Coaches

They ask first, show what could change and explain why, so the person using them builds the skill
themselves.

| Skill | What it does |
|---|---|
| [Content Review Coach](skills/content-review-coach/) | Teaches a content marketer to review a blog post, use case page, customer story or interview the way a senior reviewer would, and to finish with a decision: keep, promote, edit, restructure, rewrite or take it down |

More skills will follow.

## Install

In Claude Code:

```
/plugin marketplace add lauradcampbell/marketing-skills
/plugin install marketing-skills@lauradcampbell-skills
```

Or copy any folder from `skills/` into your own `.claude/skills/` folder.
